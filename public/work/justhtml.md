# JustHTML — Micro Framework

**Year:** 2020  
**Scope:** Frontend and framework  
**Stack:** HTML, CSS, JavaScript

JustHTML is a lightweight framework for simple websites. It provides ready-made CSS classes and JavaScript functions that can be used directly in HTML, reducing the need for separate scripts and stylesheets on small projects that do not justify a build step or component framework.

- [Source](https://github.com/Aquitano/JustHTML)
