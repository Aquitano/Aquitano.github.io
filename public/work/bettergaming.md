# BetterGaming — E-Commerce Platform

**Year:** 2021  
**Scope:** Frontend and backend  
**Stack:** PHP, MySQL, JavaScript, CSS

BetterGaming is a video-game e-commerce application using server-side PHP and MySQL for dynamic product data. Its JavaScript frontend provides Ajax-powered live search, sorting, client-side validation, PaceJS feedback, and scroll-based animation. User management uses hashed and salted passwords.
