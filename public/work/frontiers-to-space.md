# FrontiersToSpace — Stratosphere Mission

**Year:** 2023  
**Scope:** Frontend, backend, data visualization, hardware  
**Stack:** React, TypeScript, Astro, Leaflet, Chart.js

Thomas Breindl developed the frontend and website architecture for a platform visualizing measurement data from a stratospheric balloon mission. React powered interactive interfaces, Astro optimized delivery, Leaflet mapped the flight path, and Chart.js rendered sensor data as explorable charts.

He also helped build and program the probe, integrating sensors and APRS data transmission on a TTGO T-Beam. The project was completed with the German Amateur Radio Club and Passau Observatory, culminating in a Science Day event on 8 July 2023.
