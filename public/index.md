# Thomas Breindl

Thomas Breindl is a software developer, designer, and computer science student in Passau, Germany. He works on Java services, event pipelines, backend systems, and web interfaces.

## Stack

- Java, Spring Boot, Quarkus, JPA/Hibernate, Node.js, Python, and SQL
- TypeScript, React, Next.js, SolidJS, Astro, and Tailwind CSS
- Legacy modernization, distributed systems, event-driven architecture, performance, and observability
- Docker, Kubernetes, Terraform, GitHub Actions, Grafana, PostgreSQL, and self-hosted infrastructure

## Experience

- At itestra, reengineered about 21,000 lines of COBOL health-insurance logic in Java and Quarkus and built reusable copybook parsing tooling.
- At CHECK24, designed an ActiveMQ/JMS pipeline and helped cut P95 latency by 50% to about 150 ms across roughly 1.5 million daily events.
- At 4process, built SAP workflow tooling and a Java utility for validating bulk record changes.
