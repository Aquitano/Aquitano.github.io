# Thomas Breindl

Thomas Breindl is a software developer, designer, and computer science student in Passau, Germany. He works on distributed data pipelines, Go and Java services, and web interfaces.

## Stack

- Go, Java, Kotlin, Quarkus, Spring Boot, Jakarta Batch, ActiveMQ/JMS, and SQL
- TypeScript, React, Next.js, SolidJS, Astro, and Tailwind CSS
- Legacy modernization, distributed systems, event-driven architecture, performance, and observability
- Docker, Linux, GitHub Actions, Cloudflare Workers, PostgreSQL, ClickHouse, Prometheus, Grafana, and self-hosted infrastructure

## Experience

- At Cloudflare (Analytics & Alerts, 2026), shipped a compaction path for an analytics pipeline that processes 100 million events per second. It merges aggregates during downstream outages and raised retention from 51% to 77% in controlled outage tests.
- At itestra (2025 to 2026), rewrote about 31,000 lines of COBOL health-insurance logic in Java and Quarkus, cut code size by 40%, and built an annotation-driven library that maps binary COBOL copybook records to typed Java objects.
- At CHECK24 (2025), moved non-critical provider calls off the request path onto ActiveMQ/JMS and cut P95 initial response latency by 50% to about 150 ms in a system handling roughly 1.5 million events per day.
- At 4process, built SAP workflow tooling and a Java utility for validating bulk record changes.
