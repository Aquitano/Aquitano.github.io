# About Thomas Breindl

Thomas Breindl is a software developer, designer, and computer science student in Passau, Germany. He works across backend engineering, distributed systems, and interface design.

His professional work includes moving health-insurance software from COBOL to Java and Quarkus, building ActiveMQ/JMS event pipelines, and improving latency in systems handling about 1.5 million daily events.

He likes work that crosses boundaries: understanding the domain, writing the service, measuring it in production, and polishing the interface. His current interests include Java and TypeScript, legacy modernization, event-driven systems, self-hosted infrastructure, and data visualization.
